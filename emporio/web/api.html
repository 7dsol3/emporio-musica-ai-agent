Clear boundaries.

← Return to the assistant · OpenAPI schema (JSON)

The server binds to 127.0.0.1. A session is identified by an HttpOnly, SameSite=Strict cookie. Use a cookie jar when calling from a terminal. No external API key is required in local mode.

GET /api/health

Read readiness, configured planner, fixture counts and source fingerprints.

GET /api/session

Create or resume a session. Returns the redacted conversation history and verification status.

POST /api/chat

Body: {"message":"How much is the Takamine GD20?"}. Messages contain 1-2,000 characters. Returns the answer, source references, tool receipts, planner mode and audit digest.

POST /api/verify

Body: {"order_id":8,"email":"anacarol.ferreira@coldmail.com"}. This is a fictional fixture identity, provided only for local evaluation. Verification is scoped to the session. Five attempts per minute per client are allowed. Purchase email is never sent to the model.

DELETE /api/session

Delete the current session, including history, remembered context and order verification. An empty session is created.

GET /api/catalog

Optional query and category_id filters. Returns up to eight matches with availability and source IDs.

GET /api/policies

Read English policy summaries and original manual page references.

Errors: 400 unexpected Host, 403 cross-origin write, 413 oversized request, 422 invalid input, 429 rate limit. Financial and refund operations are intentionally absent from this read-only service.
